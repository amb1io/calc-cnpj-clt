# calc-cnpj-clt

Calculadora **CLT × PJ** (amb1) — mesmas fórmulas da planilha InfoMoney.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Testes e build

```bash
npm test
npm run build
```

## Deploy (manual)

```bash
npm run build
npx wrangler pages deploy dist --project-name amb1-clt-pj-calculadora --branch main
```

**Produção:** [https://calc.amb1.io](https://calc.amb1.io)

## Identidade visual

Cores amb1: verde `#BDD747`, cinza `#58585A`, fundo `#F3F3F3`, tipografia Comfortaa.
